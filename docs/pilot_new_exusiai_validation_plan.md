# 新约能天使商品专项验证计划

## 1. 审批结论

本轮从210个角色×品类候选中批准 **新约能天使** 作为首个专项验证角色，选择两个互补商品方案：

| 方案 | Candidate | 商品方向 | Pilot Score | 定位 | 当前结论 |
|---|---|---|---:|---|---|
| A | CAND-002 | 亚克力制品 | 68.76 | 主力展示款 | 批准进入专项意向与供应商核验 |
| B | CAND-006 | 吧唧（徽章） | 66.66 | 低客单验证款 | 批准进入专项意向与供应商核验 |

审批只表示允许继续调研、内容测试和询价，不表示已经采购、备货或取得销售成果。

## 2. 选择逻辑

- **角色层面**：新约能天使的跨平台内容热度为71.93、商业代理信号为61.43，并可映射到问卷中的能天使偏好数据，具备开展专项验证的优先级。
- **方案A**：亚克力制品适合呈现角色立绘，直播与内容展示适配度高，整体问卷可接受价格中位数为100元，但当前角色×品类专项样本只有2份。
- **方案B**：吧唧属于低客单、低生产风险品类，整体问卷高意愿占比为50%、可接受价格中位数为50元，同样只有2份角色专项样本。
- **未选择毛绒作为首轮方案**：毛绒候选分数最高，但打样、品控、MOQ、仓储和售后复杂度更高；首轮先以亚克力与吧唧验证角色需求和价格敏感度，毛绒保留为第二阶段观察组。

## 3. 30人专项意向收集

### 3.1 样本与配额

- 至少收集30名去重受访者，每名受访者都评价方案A与方案B，因此形成至少60条候选意向记录。
- 受访者需接触《明日方舟》不少于3个月；建议18～24岁不超过70%，避免完全复制现有大学生样本结构。
- 至少三种招募来源，单一渠道占比不超过50%；不采集姓名、手机号、账号、IP或地址。
- A/B方案展示顺序随机，图片尺寸、信息量、发货说明保持一致，避免位置和素材质量造成偏差。

### 3.2 问题设计

1. 过去12个月是否购买过《明日方舟》官方或授权周边。
2. 对新约能天使的喜爱程度，1～5分。
3. 对方案A的购买意愿、最高可接受价格、可接受预售天数。
4. 对方案B的购买意愿、最高可接受价格、可接受预售天数。
5. 两个方案必须二选一时的首选项。
6. 影响购买的主要因素：设计、正版授权、价格、材质、尺寸、发货周期、售后。
7. 常用购买渠道：官方商城、淘宝、B站会员购、线下展会或快闪店。

### 3.3 有效意向定义

同时满足以下条件记为`qualified_intent=true`：

- 已同意匿名调研说明；
- 对新约能天使喜爱程度不低于3分；
- 对对应方案购买意愿不低于4分；
- 最高可接受价格不低于该方案的测试价格下限；
- 关键字段完整且不存在矛盾价格或重复记录。

### 3.4 商品验证门槛

| 指标 | 方案A 亚克力 | 方案B 吧唧 |
|---|---:|---:|
| 专项有效样本 | ≥30 | ≥30 |
| 高意愿占比 | ≥40% | ≥40% |
| 购买意愿均值 | ≥3.50 | ≥3.50 |
| 首轮测试价格带 | 48/68/88元 | 18/28/38元 |
| 预售容忍期中位数 | ≥30天 | ≥21天 |

未达到门槛时只调整概念、价格或目标人群，不进入订单试点。

## 4. 三家供应商报价

同一批三家候选供应商需要同时对方案A与方案B报价，形成至少6条报价记录。每家必须提供：

- 官方或授权商品的可核验证据及证据有效期；
- 商品规格、材质、包装、MOQ和阶梯单价；
- 样品价格、样品周期、批量交期及运费承担方式；
- 瑕疵率容忍标准、补发/退换政策和质量问题责任；
- 付款节点、发票条件、延期处理与取消条款。

授权证据未通过时直接淘汰，不进入综合评分。通过硬门槛后，按单位成本30%、样品与质量25%、交期20%、MOQ15%、售后条款10%形成供应商评分。项目只记录内部`SUP-001`等代码，公开仓库不保存企业联系人与未脱敏合同。

## 5. 下一步执行顺序

1. 制作两张信息量一致的A/B概念卡并创建可追踪Campaign ID。
2. 发布内容预热，记录Impressions、Clicks与Landing UV。
3. 回收30名以上专项受访者并导入`pilot_intent_leads.csv`。
4. 联系至少3家供应商，完成授权证据、样品、MOQ、成本和交期核验。
5. 运行`python scripts/build_commercial_pilot.py`，由数据门禁判断是否允许进入10～20单的小批量试点。
