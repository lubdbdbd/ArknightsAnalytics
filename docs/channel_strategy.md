# 渠道策略与差异化 SKU 配置

本模块是商业化运营方法演练：原始订单与 SKU 成本为模拟数据，渠道规则为规划假设。输出不是实际销售网络、真实费率或已实现增长。

## 数据与方法
- 输入：erp_order_headers.csv、erp_order_lines.csv、erp_sku_master.csv；配置：config/channel_strategy.json。
- 先核对订单头与明细，再按支付订单关联 SKU，汇总商品金额（扣优惠、不含运费）。渠道总额与订单头独立求和核对。
- 原始7类渠道：官方商城、淘宝/天猫、B站会员购、直播间、线下展会或快闪店、二手平台、其他。
- 配置7类渠道：前述前5类，加众筹及零售代理。二手平台/其他只作观察；众筹/代理尚无订单，指标留空，不填零。
- 四维适配分：品类40%、目录价格带20%、补货周期20%、生产风险代理20%。全部权重与品类分是可调整规则，非统计学习或市场验证结果。
- 单件贡献 = 假设渠道价 × (1−渠道费率−退款金额比例) − 商品成本 − 单位变动费。未扣营销、固定成本及税费，也未模拟退货成本冲回；不得叫实际利润。
- 单件贡献率低于15%先复核成本。达到80分/60分分别进入优先评审/条件配置；未达到则暂缓。非在售SKU须先核验状态。
- 补货周期不是发货SLA，生产风险代理值不是不良率。授权、库存、账期、实际物流与供货条件需要另行确认。

## 差异化配置与价格复核
相同SKU可以跨渠道销售，差异可来自规格组合、权益、服务、供货节奏和展示方式。
同SKU、同零售价口径、已进入优先/条件评审的候选两两比较；价差/较高价达到10%进入人工复核。
代理批发出货价不与零售价比较。复核项是“SKU×渠道对”，一件SKU可能有多组，不能报成异常SKU数或已发生冲突。

默认演练得到210×7=1470条配置评估与49个品类渠道组合。同品类角色使用相同属性时会同分；本模块不证明不同角色在渠道中的真实偏好差异。
规划条件改变后应重新生成，数字会随规则变化。

## 使用
运行 python scripts/build_channel_strategy.py 生成 reports/generated/channel_strategy/report.json 与 report.md。
本地页面 /#channels 支持渠道、品类、结论、角色或SKU筛选，查看依据和假设价差，导出报告。
GET /api/channel-strategy 支持 download=markdown 或 json；不会修改订单、商品主档或运行台账。
界面与报告使用CSV快照，不包含商品维护页尚未回写快照的覆盖值。输入SHA256可追溯本次版本。
SKU/品类订单数可能跨商品重复；不可加总作为渠道独立订单数。

## 下一步真实试点
确认授权与渠道准入 → 选小批量SKU → 核实成本、权益与库存 → 明确周期及价格 → 采集成交/退款/履约 → 同口径复盘。
没有真实渠道访客、买家ID、投放花费及连续库存记录时，不推算真实转化、复购、ROI或库存周转。
