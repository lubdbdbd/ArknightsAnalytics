# 可验证选品案例方法

## 案例对象

当前使用“新约能天使”作为第一阶段案例，因为仓库同时具备角色公开内容、定向淘宝搜索和模拟 ERP 方法数据。案例不会把公开热度直接写成销量，也不会把模拟 ERP 写成真实经营结果。

## 六层证据门禁

| 证据层 | 当前门槛 | 数据性质 |
|---|---:|---|
| 跨平台内容热度 | `Cross-platform Heat >= 60` | 真实公开聚合 |
| 深层互动意向 | `Intent Score >= 70` | 真实公开聚合 |
| 定向搜索质量 | `Search Precision >= 60%` | 真实公开快照 |
| 淘宝需求代理 | 公开收货人数下界合计不低于 100 | 真实公开下界代理 |
| 固定 SKU 时间序列 | 至少 C 级 | 真实公开纵向数据 |
| 匿名用户调研 | 至少一个细分 `n >= 30` | 真实匿名问卷 |

前四层通过、后两层未通过时，案例状态只能是 `conditional_pilot`，含义是“可进入小批量验证”，而不是“已经证明会卖”。六层全部通过后才升级为 `validated_candidate`。

## 决策输出

- 低风险验证款：徽章、纸品和亚克力，验证收藏、加购与付款转化。
- 中风险承接款：在时间序列增长和价格接受度同时通过后增加毛绒或组合套装。
- 高风险品类：服饰、手办等在缺少真实订单和履约数据时只做预售，不做现货重仓。
- 真实验收：预售转化、售罄率、退款率、客诉率、库存周转与复购意愿。

自动生成案例见 `reports/generated/selection_case_study.md`，机器可读证据见 `data/processed/selection_case_evidence.csv`。
