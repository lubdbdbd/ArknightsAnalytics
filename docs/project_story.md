# 项目叙述口径

## Business Goal

ACG 周边选品容易把社区声量直接等同于购买需求，导致热门角色备货过度、长尾角色缺货或高客单商品库存积压。本项目希望建立一套可解释的“角色热度—品类适配—库存风险”分析链路，为选品、预售和直播排品提供量化假设。

## Technical Approach

1. 采集官方公开视频的播放、点赞、投币、收藏和弹幕等聚合指标，不采集用户个人信息。
2. 对发布时间进行归一化，使用播放速度和互动质量构建 `Heat Score`，降低老视频累计播放量的直接优势。
3. 将徽章、立牌、色纸、毛绒、手办和服饰拆分为不同价格、成本、直播适配和生产风险。
4. 在缺少真实企业 ERP 的情况下使用固定随机种子构造模拟订单，并通过 `is_simulated` 防止与真实销量混淆。
5. 使用 SQLite 和 SQL 计算选品、毛利、售罄、退货和库存风险，最终输出报告、Excel 看板与直播候选清单。

## Quantified Baseline

- 首批整理10条官方限定干员PV公开快照，覆盖2022—2026年。
- 识别10名角色，生成6个品类、60个模拟SKU。
- 当前样本中，予愿安洁莉娜、荒芜拉普兰德和望的复合热度排名前三。
- 模拟选品中，低客单色纸、徽章与亚克力立牌更适合优先完成需求验证；高客单手办虽贡献较高模拟GMV，但库存与生产风险更高，不应仅按GMV决策。

以上结论是方法演示，不代表官方销量或真实商业结论。正式决策需要继续补充用户问卷、收藏加购、历史订单和真实退货数据。
