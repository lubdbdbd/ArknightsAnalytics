# 博士，想听听你对《明日方舟》周边的想法

> 版本：v2.2｜预计用时：5～8分钟｜本问卷用于个人学习项目中的用户需求研究

你好，博士！

我们正在尝试了解大家平时会关注、购买什么样的《明日方舟》官方或正版授权周边，也想知道哪些设计、价格或购买体验会影响你的选择。本文所说的“周边”均指官方或正版授权商品，不讨论盗版及无授权商品。问卷没有标准答案，按照你的真实习惯填写就好。

本次填写全程匿名，不会收集姓名、手机号、游戏账号、IP或住址。结果只会以汇总形式用于项目分析，不会展示任何单份回答。感谢你愿意和我们分享想法！

## 1. 我在项目中如何参与用户调研

我负责把“角色内容很火”进一步验证成“玩家是否真的愿意购买”的完整调研过程：

1. **先确定要解决的问题**：想知道玩家喜欢哪些角色、希望看到什么品类、能接受怎样的价格和预售时间，以及最终放弃购买的原因。
2. **先小范围试填，再正式发放**：先邀请5～8名玩家边填边说出自己的理解，修改难懂或容易误解的题目；再收集30～50份试填结果，检查题目是否过长、选项是否遗漏；最后再面向多个玩家社区收集约300份正式答卷。
3. **让问题更像真实购物场景**：不直接问“你是否支持IP商业化”，而是询问过去买过什么、最想买谁的周边、看到具体商品时是否想买、什么价格会犹豫、什么原因会劝退。
4. **避免只听到一种玩家的声音**：从至少3个社区渠道招募，既包括经常买谷的玩家，也包括偶尔购买、只关注角色和暂时没有购买经历的玩家。
5. **后台处理数据问题**：问卷页面不设置刻意的“检查题”；导入数据后只通过完成时间、重复记录、字段范围和前后逻辑进行清洗，不干扰正常填写体验。
6. **把回答转成运营建议**：使用Python/Pandas分析用户分群、角色与品类组合、购买意愿、价格区间、预售接受度和主要劝退原因，并与B站内容热度、淘宝商品快照和固定SKU后续表现交叉验证。
7. **先小量验证，不用问卷直接压货**：问卷只帮助筛出值得尝试的角色和品类；真正进入备货前，还要通过收藏、加购、付款、退款、发货和复购数据继续验证。

## 2. 这份问卷想回答什么

| 想了解的问题 | 观察内容 | 对运营有什么帮助 |
|---|---|---|
| 内容热度能不能转化成购买意愿 | 角色选择、购买意愿、历史购买情况 | 判断角色是否值得进入商品概念测试 |
| 不同角色适合做什么周边 | 角色Top-3、首选品类、商品概念反馈 | 调整亚克力、通行证、吧唧、毛绒、模玩、摆件和日用货盘 |
| 玩家对价格的真实感受 | 合适价格、超过多少会放弃 | 形成小批量试销的价格范围 |
| 预售和履约会不会劝退玩家 | 可接受等待时间、购买顾虑 | 调整现货/预售方式和发货沟通 |
| 不同用户的需求是否不同 | 购买次数、消费区间、购买阻力 | 区分核心购买者和潜在购买者 |

这些结果只代表本次参与者的反馈，不能直接描述成“所有《明日方舟》玩家都这样认为”。

## 4. 发放方式与后台分析

### 发放前

1. 邀请5～8名玩家试填，重点追问“你觉得这道题在问什么”“有没有选项不符合你的情况”。
2. 收集30～50份预测试，检查中位完成时间、跳题是否正常、哪些题经常被跳过、开放题是否能得到有效回答。
3. 正式问卷目标约300份有效回答，至少来自3个不同社区，单一来源不超过50%。

### 后台清洗

- 问卷页面不插入与周边调研无关的验证题。
- 仅排除未同意研究说明、完成时间明显异常、重复提交、字段超出合理范围或价格回答前后冲突的记录。
- 任何清洗规则都在分析前确定，不根据结果临时删除“不好看”的回答。

### 输出结果

- 用户分群：核心购买者、偶发购买者、潜在购买者、暂时不购买的观察者。
- 角色×正版品类：最受欢迎的角色商品组合及“要看价格/成品”的犹豫人群。
- 价格：各品类合适价格和劝退价格分布。
- 购买阻力：价格、设计、品质、预售、运费和售后的提及比例。
- 商品概念：A/B款偏好、吸引点和购买前最关心的信息。
- 运营验证：与B站内容热度、淘宝公开商品和固定SKU后续收藏、加购、付款表现交叉验证。

## 5. 面试介绍口径

> 为补足内容热度无法直接代表周边购买需求的问题，我设计了一份更贴近国内游戏玩家交流习惯的25题匿名问卷。问卷先从玩家接触时间和真实购买习惯聊起，再进入角色Top-3、首选品类、具体商品概念、合适价格、预售接受度和劝退原因，全部使用玩家容易理解的日常表达。执行上先做5～8人试填访谈，再进行30～50份预测试，最后计划从至少3个社区获取约300份有效回答。问卷不插入与周边调研无关的验证题，后台只对明显过快、重复、范围异常和前后冲突的数据做透明清洗。分析结果会与B站内容热度、淘宝商品快照和固定SKU后续表现一起使用，只用于筛选小批量试销候选，不把“说想买”直接当成真实销量。

## 6. 参考样式

- 《重返未来：1999》公开版本满意度问卷采用“司辰/Timekeeper”称呼、约5分钟说明、五档口语满意度、未参与跳题、最多选择3项和结尾开放反馈，整体语气更像邀请玩家交流，而不是学术量表。
- 公开《明日方舟》玩家意向问卷常用入坑时间、消费档位、偏好排序和具体游戏场景来帮助玩家回忆，说明选项应贴近玩家经历而不是只给抽象数字。
