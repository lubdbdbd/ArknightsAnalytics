# 《明日方舟》IP衍生品用户需求与选品调研问卷

> 版本：v2.0｜预计用时：5～7分钟｜对象：年满18周岁的《明日方舟》玩家或IP衍生品潜在消费者

## 1. 项目参与方法

我在项目中承担从研究问题定义到运营建议落地的完整用户调研链路：

1. **业务问题定义**：验证“内容热度高”是否能转化为角色周边购买意愿，并识别适配品类、价格区间、购买渠道和主要阻力。
2. **研究设计**：采用“5～8人认知访谈→30～50份预测试→300份正式问卷→固定SKU小规模验证”的三阶段设计，而不是直接大规模发放未经验证的问卷。
3. **问卷设计**：将玩家背景、真实消费行为、角色偏好、品类选择、商品概念、价格阶梯和购买阻力拆分测量，避免把多个问题写在同一道题中。
4. **招募与配额**：至少使用3个独立来源招募，限制单一来源不超过50%，并分别覆盖核心购买者、偶发购买者、潜在购买者和仅关注内容的用户。
5. **数据治理**：匿名采集，不保存姓名、手机号、账号、IP和住址；通过知情同意、完成时长、注意力题、重复记录、范围校验和价格阶梯一致性清洗答卷。
6. **分析与决策**：使用Python/Pandas输出有效率、用户分群、角色×品类意愿、高意愿占比、价格四分位、购买阻力和预售容忍度，并与B站内容热度、淘宝公开商品快照和固定SKU时间序列交叉验证。
7. **业务闭环**：调研只决定“是否进入小批量试销”，不直接决定大规模备货；候选商品仍需通过收藏、加购、付款、退款、履约与复购指标验证。

## 2. 研究假设与验收标准

| 假设 | 对应指标 | 方向性门槛 | 后续动作 |
|---|---|---:|---|
| 高内容热度角色存在真实商业需求 | 购买意愿、高意愿占比 | 细分样本≥30且高意愿占比≥40% | 进入概念测试 |
| 角色与品类存在适配差异 | 角色×品类意愿、Top-3品类 | 同角色不同品类差异≥0.5分 | 调整商品组合 |
| 用户存在可解释的价格区间 | 可接受价格P25/P50/P75、价格阶梯 | 价格回答单调且样本≥30 | 形成方向性价格带 |
| 预售周期影响转化 | 预售容忍天数、购买阻力 | “周期过长”进入Top-3阻力 | 缩短周期或强化进度通知 |
| 购买者与未购买者诉求不同 | 分群意愿、预算、阻力 | 分群差异可复核 | 分层触达与货盘 |

所有门槛都是项目预设的运营筛选条件，不代表统计学显著性。便利抽样结果不得描述为全体玩家比例。

## 3. 正式问卷

### A. 知情同意与筛选

- 同意，继续填写
- 不同意，结束问卷

**Q2【单选/必答】** 您的年龄区间是？

- 18～24岁

- 36岁及以上

**Q3【数字/必答】** 您接触《明日方舟》或其角色内容大约多少个月？`0～120`

**Q8【数字/必答】** 未来一个月可用于ACG周边的预算约多少元？`0～10000`

**Q9【单选/必答/随机选项】** 您通常最愿意从哪个渠道购买？

- 官方商城

**Q11【最多选3项/必答/随机选项】** 哪些因素最容易让您放弃购买？

### C. 角色与品类需求

**Q12【排序题/必答/角色顺序随机】** 请从候选角色中选择最多3名最愿意购买周边的角色，并按意愿排序。

**Q13【单选/必答/随机选项】** 对您排名第一的角色，最希望购买哪一种周边？

- 徽章/吧唧

- 挂件/钥匙扣
- 毛绒
- 服饰/箱包
- 手办/模型
- 家居或实用品
- 数字权益

**Q14【1～5分/必答】** 如果该角色推出上述品类，您的购买意愿是？`1=完全不会购买，5=非常愿意购买`

**Q15【1～5分/必答】** “限量、联名或活动限定”对您的吸引力是？`1=没有吸引力，5=非常有吸引力`

## 4. 招募与样本设计

### 4.1 三阶段执行

1. **认知访谈5～8人**：要求参与者边填写边复述理解，发现术语、选项和跳题歧义。
2. **预测试30～50份**：检查中位完成时间、漏答率、价格异常率、开放题可用性和选项覆盖。
3. **正式问卷目标300份有效样本**：来自至少3个独立渠道；单一来源≤50%，单一角色×品类未达到30份时只作探索性结果。

### 4.2 建议配额

| 维度 | 建议配额 |
|---|---|
| 既往购买行为 | 购买者50%～70%，未购买者30%～50% |
| 活跃程度 | 过去30天0～9天、10～19天、20～30天均有覆盖 |
| 招募来源 | B站、微博/社区、线下或QQ群等至少3类，单一来源≤50% |
| 用户类型 | 核心购买者、偶发购买者、潜在购买者、观察者均保留 |

## 5. 自动化清洗与分析

问卷平台导出后映射到 `data/manual/survey_template.csv`，执行：

```powershell
.\.venv\Scripts\python.exe scripts\import_survey_responses.py path\to\survey_export.csv
.\.venv\Scripts\python.exe scripts\run_pipeline.py
```

自动输出：

- `survey_response_audit.csv`：同意、完成时间、注意力、重复、范围与价格阶梯审计。
- `survey_operator_category_summary.csv`：角色×品类意愿、价格和证据等级。
- `survey_segment_summary.csv`：四类用户的规模、预算、购买意愿和预售容忍度。
- `survey_barrier_summary.csv`：购买阻力人数与占比。
- `survey_price_summary.csv`：可接受价格四分位及方向性价格上下界。
- `user_research_report.md`：可直接用于复盘和面试展示的调研报告。

## 6. 面试介绍口径

> 为补足公开内容热度无法代表真实购买需求的问题，我设计了三阶段衍生品用户调研：先通过5～8人认知访谈验证题目理解，再以30～50份预测试检查完成时长和选项覆盖，最终计划获取300份匿名有效问卷。问卷覆盖玩家活跃度、历史消费、角色与品类偏好、概念吸引力、价格阶梯、预售容忍度和购买阻力，并通过选项随机、注意力题、价格单调校验和多渠道配额降低偏差。工程上使用Python/Pandas完成匿名答卷导入、质量审计、用户分群、角色×品类需求、价格区间和阻力分析，再与B站内容热度、淘宝商品快照及固定SKU时间序列交叉验证。调研结果只用于筛选小批量试销候选，不把购买意愿直接等同于真实销量。
